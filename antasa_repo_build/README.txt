ANTASA MUSIC - starter Android project

Status:
- Local audio library using MediaStore
- Play/pause/next using Media3 ExoPlayer
- Dark Compose interface
- Streaming tab is a placeholder; it does not fetch or play online music yet.
- Background playback/notification, playlists, favorites, artwork and search are not implemented yet.

To build:
1. Open this folder in Android Studio.
2. Allow Gradle sync.
3. Connect an Android phone with USB debugging enabled, or use an emulator.
4. Run the app.
5. To create an APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

Streaming must use an authorized source; do not use unauthorized copies or scrape paid services.
